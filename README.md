Instrucciones de ejecución:
-Clonar el repositorio y abrir proyecto.
-Iniciar el programa ejecutando la clase "Main" en el package vista.
 Version de Java utilizada: Oracle OpenJDK 24.0.1.
(Verificar en File -> Settings -> Editor -> Gui Designer la opción de Generate GUI esté seleccionada en "Java on source code compilation")
-El programa mostrará la ventana principal del proyecto, en donde se incluyen las siguientes funcionalidades:
1. Crear región
2. Crear comuna
3. Crear estación meteorológica
4. Instalar sensor
5. Registrar medición
6. Cambiar estado de sensor
7. Cargar datos
8. Importar datos de texto
9. Guardar datos
10. Generar Listados
11. Salir (Finaliza y cierra el programa)
-
## Archivos de datos

- regiones.txt: contiene las regiones
- comunas.txt: contiene las comunas
- estaciones.txt: contiene las estaciones meteorológicas
- sensores.txt: contiene los sensores
- mediciones.txt: contiene las mediciones
- meteorologia.dat: contiene los objetos del sistema serializados a partir de los archivos TXT

Todos estos archivos están en la carpeta datos.
